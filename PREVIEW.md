# Review Beyond the Persona before publication

The redesign is on the local branch `redesign/classical-mediterranean`. Main, production configuration, database migrations and `server.js` are unchanged. This branch is based on `redesign/editorial-review` at commit `78cc1cc`. No push or deployment is required to review it.

## Local visual preview

With Node.js 20 or later, from the repository directory:

```sh
git switch redesign/classical-mediterranean
npm run preview
```

Open http://localhost:3001. The preview script uses only Node's built-in modules, so it works without installing dependencies or creating an `.env` file. It binds to your own computer's loopback interface by default.

### Windows local preview

After transferring or extracting this branch's source onto your Windows computer, open PowerShell in the repository directory and run:

```powershell
node scripts/preview.js
```

Open http://localhost:3001 **on that same Windows computer**. No `npm install` or `.env` is required for the visual preview.

### Codex cloud environment

`localhost:3001` on Windows cannot reach a server inside Codex cloud. If the interface offers a supported forwarded-port preview, use:

```sh
PREVIEW_HOST=0.0.0.0 npm run preview
```

Then forward cloud port 3001 and open the URL generated by that interface. This session does not expose a port-forwarding tool, so a clickable cloud URL cannot be supplied automatically. Listening on `0.0.0.0` alone does not create public hosting or a browser-accessible URL.

Use the locally generated screenshots if no forwarding feature is available. Do not deploy to Render just to preview this branch.

Review Home, Essays, an individual sample essay, About and Contact. Resize the browser or use mobile device emulation. All preview pages have a prominent preview label. The sample essays are identified as demonstration content, not writing or experiences attributed to Paula. They are never saved to a database.

### Preview category artwork

The sample cards explicitly map Life to `life-dna.jpg`, Reflection to `reflection-monk.jpg`, Philosophy to `philosophy-thinker.jpg`, Consciousness/Identity to `consciousness-identity-mirror.jpg`, and Artificial Intelligence to the existing human–AI illustration. On Essays, the selected filter determines the sample card image. All and Home use each sample's first category. Author-selected covers still take priority.

This behavior is provided by `scripts/preview-category-images.js`, served and injected only by `scripts/preview.js`. Production HTML, image selection and article records are untouched. The earlier classical source ZIP predates the category integration and still contains the statue fallback; use the updated working copy with the four JPEGs and both preview scripts. Restart the preview server and refresh the browser after replacing files. A server still running from another extracted folder will keep serving that folder's files.

Stop the preview with Ctrl+C. If the port is already used, set `PREVIEW_PORT` to another port when running the command (for example, `PREVIEW_PORT=3005 npm run preview` on macOS/Linux).

This preview is read-only: it does not load `.env`, initialise Supabase, start the production server, or support login/publishing. Use the automated isolated tests below to check the real application workflows without production access.

## Run the isolated regression tests

```sh
npm ci
npx playwright install chromium
npm test
```

If Chromium is already installed, use its executable instead of downloading a browser. On Linux:

```sh
CHROMIUM_PATH=/usr/bin/chromium npm test
```

Tests run the unchanged Express application with the `pg` module substituted by a disposable `pg-mem` database. They prevent `.env` loading and disable Supabase configuration in the child process. Test accounts and posts exist only in memory. Ports 3102 and 3103 are local test ports; set `TEST_PORT` if 3102 is occupied.

Checks cover public pages at 320, 390, 768, 1024 and 1440 pixels; automated WCAG A/AA checks; topic filters; keyboard navigation; reduced motion; text resizing; error/retry, empty and missing-content states; content escaping; author login, drafts, editing, preview, links, publishing, deletion and logout; CSRF and ownership enforcement.

Image-upload UI behavior is tested with an intercepted response. The real route's unavailable-storage response is also checked. Real Supabase uploads, production cookies/proxy behavior and the live PostgreSQL schema are deliberately not tested.

Review screenshots are written to ignored `work/review/` by default. Use `SCREENSHOT_DIR=work/classical/review` to keep this version separately. Automated checks supplement, but do not replace, visual and assistive-technology review.

## Artwork and visual review

The full artwork is separate from the live HTML/CSS. See `public/images/ARTWORK.md` for asset provenance and limitations. Facial details require visual approval; original text-free source artwork can be substituted for pixel-exact fidelity.

Author-uploaded covers retain priority. Without a cover, the presentation selects an illustrated author scene for consciousness/identity, the human–AI scene for AI/technology, a sculpture for life/reflection, and a classical terrace otherwise.
